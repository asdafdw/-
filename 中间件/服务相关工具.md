## 端口攻击思路

### ftp

 21端口     

1.爆破账户密码，然后用命令行登录进去：

```
ftp 目标ip         
```

2.ftp配置匿名登录

3.目标主机使用服务软件搭建ftp协议，目标软件上存在漏洞

### ssh

22端口

1.工具爆破root密码【目标是linux系统】

### rdp

3389端口

1.工具爆破账户密码

### vnc

5900，5800端口。vnc是类似于向日葵之类的第三方远控软件

1.九头蛇爆破密码

## hydra九头蛇

hydra是一个自动化爆破工具，是一个支持众多协议的爆破工具，已经继承在kaillinux中，可以直接用终端打开

端口服务攻防大致可以分为口令爆破，未授权和随机漏洞，口令爆破可以借助hydra

hydra参数说明

```
hydra -l 要爆破的用户名 -P 密码字典 ip地址 要爆破的协议 -V(把爆破过程展现出来)
g:hydra -l zyjsuper -P top500.txt 192.1681.107 rdp -V     
        -L 用户名字典                      也可以不写协议直接写端口
eg:hydra -L ftp-user.txt -P ftp-pass.txt 192.168.1.107:21 -V
```
