攻击者想要获取一台主机的信息，但是这台主机不与攻击者产生连接或攻击者权限不够，但是这台主机对服务器无条件信任，它要什么主机就给什么，攻击者通过欺骗带有ssrf漏洞的服务器让服务器向这台主机索取攻击者想要的信息，服务器接收并返回给攻击者

- 常用于攻击内网或获取内网信息 

 ![](C:\Users\19746\Desktop\网络安全\图片\屏幕截图 2023-08-05 165317.png)

- 需要掌握各种协议的用途

- 由于SSRF的原理是我们通过服务器来攻击主机，一般我们连接不到主机的，所以利用漏洞时我们想要直接在url处或通过浏览器直接攻击是不可能的，我们必须在一个服务器（比如服务器开放的一个网站可以进行远程文件下载地址的输入,我们必须在该网站的远程文件下载地址输入处进行攻击，而不能在url处尝试直接攻击）来进行攻击

- 使用ssrf时一定要在前面附带协议，这里以上文网络图片为例子讲解ssrf的原理：

我们在实现上传网络图片功能的输入处输入协议+域名（比如https://127.0.0.1),此时页面网站也就是服务器就会尝试访问该地址，本来我们是访问不到该地址的（比如内网），但是目标为了实现上传网络图片功能会选择与一些服务器产生联系，我们通过这些服务器就可以连接到目标，那假如此时我们尝试协议+域名+端口，我们就可以试探出目标的端口开放情况（根据协议的不同决定返回内容的格式不同，根据端口是否开放决定返回的状态码的不同，我们根据状态码或者返回是否正常就可以判断出目标的这一端口是否开放）

- file协议： 在有回显的情况下，利用 file 协议可以读取任意文件的内容
- dict协议：泄露安装软件版本信息，查看端口，操作内网redis服务等
- gopher协议：gopher支持发出GET、POST请求。可以先截获get请求包和post请求包，再构造成符合gopher协议的请求。gopher协议是ssrf利用中一个最强大的协议(俗称万能协议)。可用于反弹shell
- http/s协议：探测内网主机存活
